Fundamentos da web

O que é uma página estática

É um documento digital na internet com conteúdo fixo. Ela é enviada ao navegador do usuário exatamente do jeito que foi salva no servidor. Todos os visitantes veem a mesma informação, sem mudanças automáticas.

Principais Características

  • Feita com códigos básicos como HTML e CSS para estruturação e seu design leve.
  • Não precisa de banco de dados nem de servidores complexos.
  • Carrega muito rápido em qualquer navegador web.
  • É mais segura contra invasões por não ter vulnerabilidades.

Onde é Usada

  • Páginas de Contato ou Sobre para empresas.
  • Portfólios de fotos e trabalhos bem criativos.
  • Sites institucionais simples de empresas em crescimento.
  • Landing Pages de alta conversão.

O que é uma página dinâmica

Uma página dinâmica é um site ou arquivo web cujo conteúdo muda em tempo real. Ela se adapta de acordo com o usuário, o horário, a localização ou dados vindos de um banco de dados.

Como Funciona

  • Usa linguagens de programação no servidor (como PHP, Python ou Node.js).
  • Consulta bancos de dados para buscar informações atualizadas a cada acesso.
  • Modifica o visual ou os textos no navegador usando JavaScript.

Principais Exemplos

  • Redes sociais (mostram o feed de cada pessoa) dinamicamente.
  • Lojas virtuais (exibem produtos, preços e estoque) atualizados.
  • Portais de notícias (atualizam manchetes sozinhas) automaticamente.

Caminho básico entre navegador, servidor e resposta.

  1. Digitação da URL: Você digita o endereço de um site no navegador e aperta enter.
  2. Busca do IP (DNS): O navegador consulta o DNS para transformar o nome do site em um número de IP do servidor.
  3. Envio da Requisição (Request): O navegador envia um pedido via protocolo HTTP/HTTPS pela internet até o destino.
  4. Processamento no Servidor: O servidor recebe o pedido, busca as informações necessárias ou roda códigos internos.
  5. Envio da Resposta (Response): O servidor devolve os dados (como códigos HTML, CSS e imagens) de volta ao navegador.
  6. Exibição da Tela: O navegador lê esses códigos e monta o site visualmente para você.
